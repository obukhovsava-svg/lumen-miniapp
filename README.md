# ЛЮМЕН — Ночной экспресс

Бесконечный кооперативный 3D-забег для двоих: неоновые станции, два пилота и световой поезд. Новые сектора, растущая сложность, общая энергия, серия без ошибок и рекорд. Финальной станции нет: рейс продолжается, пока хватает энергии.

**Играть / URL Telegram Mini App:** https://obukhovsava-svg.github.io/lumen-miniapp/

Играйте онлайн на двух устройствах или вдвоём на одном экране. На телефоне доступны джойстики; на компьютере — клавиатура. Лучший законченный рейс хранится на устройстве.

Этот репозиторий содержит только собранный веб-клиент. Исходники остаются в приватном репозитории. Cloudflare Workers + Durable Objects обслуживают комнаты, симуляцию, энергию и счёт.
